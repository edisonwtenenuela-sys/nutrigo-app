# Admin Module Structure

## Purpose
Review, moderation, and verification workflows.

## Widgets
- `widgets/layout/`: headers, titles, generic action cards.
- `widgets/panels/`: navigator and panel composition blocks.
- `widgets/verification/`: entrepreneur verification widgets.
- `widgets/nutritionist/`: nutritionist verification widgets.

## Naming Rules
- Use `admin_*` prefix for admin widgets.
- Keep role-specific review UI in its dedicated folder.
