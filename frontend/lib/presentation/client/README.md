# Client Module Structure

## Purpose
Client-facing shopping, orders, appointments, and profile experiences.

## Profile Widgets
- `widgets/layout/`: section containers and structural blocks.
- `widgets/form/`: editable inputs/selectors/actions.
- `widgets/state/`: badges and error/empty state UI.
- `widgets/account/`: privacy and account-related blocks.

## Naming Rules
- Put reusable visual shells in `layout/`.
- Put interactive input controls in `form/`.
- Keep status/error/feedback atoms in `state/`.
